# Laundry Service Landing Page with interactive button Task-9

A responsive laundry service landing page built using **HTML5** and **CSS3**. This project demonstrates the use of Flexbox, Media Queries, and Responsive Web Design principles.
with hamburger menu

## 🚀 Features

- Responsive Navigation Bar
- Hero Section
- Call-to-Action Button
- Responsive Layout
- Mobile-Friendly Design
- CSS Hover Effects
- Separate Responsive CSS File
- interactive button
## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- Media Queries
